## 🔮 Як це відкрити та налаштувати (спойлер: не просто в GitHub)

Переглядати цей волт прямо в інтерфейсі GitHub — можна, але ви побачите лише бліду тінь того, як усе виглядає насправді. GitHub не знає, що таке Obsidian-волт, і рендерить файли як звичайний Markdown, тому:

- `[[Вікі-посилання]]` лишаються неклікабельними — це просто текст у подвійних дужках, без переходів між нотатками.
- Callout-блоки (`[!infobox]`, `[!quote]`, `[!abstract]`) виглядають як звичайні цитати без кольору, іконок і стилю, закладеного темою.
- Вбудовані зображення `![[файл.png]]` не рендеряться без рушія Obsidian — GitHub просто не розуміє цей синтаксис вбудовування.

Щоб отримати повноцінний досвід — з клікабельними зв'язками, стилізованими інфобоксами та коректними зображеннями — волт потрібно відкрити в самому Obsidian. Нижче покроковий гайд.

### 1. Встановлення Obsidian

Завантажте застосунок з офіційного сайту [obsidian.md](https://obsidian.md) — він безкоштовний для особистого використання та доступний під усі основні платформи:

- **Windows** — інсталятор `.exe`.
- **macOS** — пакунок `.dmg`.
- **Linux** — `.AppImage`, `.deb` або пакунок через Flatpak.

Встановіть застосунок і запустіть його — далі знадобиться сам проєкт.

### 2. Перенесення проєкту

Є два способи отримати файли волту на свій комп'ютер.

**Варіант А: через Git**

Якщо у вас встановлений Git, просто клонуйте репозиторій:

```bash
git clone https://github.com/maks75736/World_of_Warcraft_Lore.git
```

Цей спосіб зручний тим, що надалі оновлення бази зводяться до однієї команди (див. пункт 7).

**Варіант Б: через ZIP-архів**

Якщо Git не потрібен або незручний:

1. Натисніть кнопку **Code** на сторінці репозиторію.
2. Оберіть **Download ZIP**.
3. Розпакуйте архів у зручну для вас папку.
4. У Obsidian на стартовому екрані оберіть **Open folder as vault** і вкажіть розпаковану папку.

### 3. Встановлення теми ITS Theme

Волт розрахований на тему **ITS Theme**, без якої частина оформлення (зокрема інфобокси) виглядатиме інакше:

1. Перейдіть у **Settings → Appearance → Themes → Manage**.
2. У пошуку введіть `ITS Theme`.
3. Знайдіть тему авторства **SlRvb** і натисніть **Install and use**.

### 4. Плагіни для візуалу

1. Перейдіть у **Settings → Community plugins** і натисніть **Enable** (якщо спільнотні плагіни ще не увімкнені).
2. У пошуку плагінів знайдіть **Style Settings** і встановіть його.
3. Відкрийте налаштування **Style Settings** і перейдіть до розділу **ITS Theme Settings → Alternate Color Schemes → TTRPG**.
4. Оберіть профіль **`Pathfinder`** — саме під нього стилізовані інфобокси та акценти цього волту.

### 5. Корисні плагіни

Не обов'язкові, але значно покращують роботу з волтом:

- **Dataview** — дозволяє будувати динамічні списки й таблиці на основі метаданих нотаток (наприклад, автоматичний перелік усіх персонажів чи локацій).
- **Obsidian Git** — інтегрує Git прямо в інтерфейс Obsidian: коміти, пуші та пули без переходу в термінал.
- **Hover Editor** — показує попередній перегляд нотатки при наведенні на `[[вікі-посилання]]`, без потреби відкривати її повністю.

### 6. Сніпет infobox.css

Для коректного відображення бічних інфобоксів і зображень без зайвого затемнення потрібен CSS-сніпет.

Створіть файл за шляхом:

```
.obsidian/snippets/infobox.css
```

І вставте в нього такий код:

```css
/* infobox.css — стилізація бічних інфобоксів та скидання затемнення зображень */

/* Інфобокс, що плаває праворуч від основного тексту */
.callout[data-callout-metadata*="right"] {
  float: right;
  width: 320px;
  max-width: 40%;
  margin: 0 0 1em 1.5em;
  clear: right;
  position: relative;
  z-index: 5;
}

.callout[data-callout-metadata*="right"] .callout-title {
  font-weight: 600;
}

.callout[data-callout-metadata*="right"] .callout-content {
  font-size: 0.9em;
  line-height: 1.4;
}

.callout[data-callout-metadata*="right"] img {
  width: 100%;
  height: auto;
  border-radius: 6px;
  margin-top: 0.5em;
}

/* Скидання стандартного затемнення зображень Obsidian у темній темі */
.theme-dark .markdown-preview-view img,
.theme-dark .markdown-source-view img {
  filter: brightness(100%) !important;
  opacity: 1 !important;
}
```

Після створення файлу активуйте сніпет:

1. Перейдіть у **Settings → Appearance → CSS snippets**.
2. Натисніть кнопку оновлення списку (іконку перезавантаження), щоб Obsidian побачив новий файл.
3. Увімкніть перемикач біля **infobox**.

### 7. Оновлення бази

Лор постійно доповнюється, тож варто регулярно синхронізувати локальну копію з репозиторієм.

- **Якщо клонували через Git** — достатньо виконати в папці волту:

```bash
git pull
```

- **Якщо завантажували ZIP** — потрібно повторно скачати архів і перезаписати файли, **не чіпаючи** папку `.obsidian` (у ній зберігаються ваші локальні налаштування, тема та плагіни).

### 8. Фінал

Усе готово. Натисніть **Ctrl+G** (Windows/Linux) або **Cmd+G** (macOS), щоб відкрити граф зв'язків, і поринайте в лор — тепер з клікабельними посиланнями, стилізованими інфобоксами та коректно відображеними зображеннями.
