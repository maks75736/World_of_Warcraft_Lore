## 🍺 Що це за звір такий

Це — **особистий Obsidian-волт** одного дуже впертого лороголіка, створений для структуризації та адаптації лору Warcraft українською мовою: спираючись на канон, термінологію спільноти, з блекджеком і без жодних кальок з російської.

Усередині зібрані титани, Старі Боги, дві вічно бунтуючі фракції та купа героїв із хронічною кризою ідентичності. Усе це акуратно розкладено по поличках (00–09), намертво зшито мережею [[вікі-посилань]] і загорнуто в стильні плаваючі інфобокси під класичну Warcraft Wiki.

> [!warning] Це не Fandom і не офіційний лор-хаб
> Це чернетка одного волту. Частина сторінок — це вичерпні розділи на 200+ рядків. Частина — просто назва файлу і порожнеча всередині, як душа після зустрічі з Королем-лічем.

## 📖 Словник — священна книга проти "Плєті" й "Нордскола"

Файл `00 Медіа та Хаби/Словник.md` — це не просто список термінів, це **маніфест**. Три залізних правила:

1. 🎯 Змістовий переклад для описових назв (*Frostmourne* → **Фростморн**, *Silvermoon* → **Срібномісяць**)
2. 🔊 Фонетична транскрипція для незалежних назв (*Northrend* → **Нортренд**, *Tichondrius* → **Тікондрій**)
3. 🚫 **Категорична відмова від російських кальок** — жодних "Нордскол", "Луносвет", "Плеть"

Всередині — таблиці по географії, персоналіях, фракціях та артефактах з поясненнями "чому саме так, а не інакше". Якщо колись сумніваєшся, як писати ім'я — відповідь там.

## 🔮 Як це відкрити та налаштувати (спойлер: не просто в GitHub)

Цей репозиторій — повноцінний **Obsidian vault**[cite: 1]. Сам по собі GitHub непогано показує `.md`-файли, але він не здатний передати всю інтерактивність:
- `[[Вікі-посилання]]` у браузері залишаються мертвими рядками замість швидких переходів[cite: 1].
- Callout-блоки на кшталт `[!infobox]`, `[!quote]` чи `[!abstract]` виглядають як сухі цитати без стилізації[cite: 1].
- Внутрішні вбудовування зображень `![[файл.png]]` — це спеціальний синтаксис Obsidian, який браузер не відобразить[cite: 1].

Щоб отримати справжній цифровий кодекс Азерота з інтерактивними картками, графом зв'язків та атмосферною темою, виконайте ці кроки
`кроки по налаштуванню.md`
